# Extension icons

Drop your extension icons here with these exact filenames:

- `icon-16.png` — 16×16 — toolbar/favicon
- `icon-32.png` — 32×32 — Windows context
- `icon-48.png` — 48×48 — extension management page
- `icon-128.png` — 128×128 — Chrome Web Store listing

Use a transparent PNG with the visual subject centered. The Chrome Web Store
strongly recommends a non-trivial 128×128 icon — placeholder or low-quality
icons are a common rejection reason.
